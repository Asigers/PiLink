# Local operations

- Confirm the target workspace and intended outcome before making broad changes.
- Inspect repository status and existing changes before editing.
- Never overwrite unrelated user work.
- Keep changes scoped to the requested project.
- Review diffs and run relevant tests after modifications.
- Ask for approval before destructive operations, privileged commands, deployments, external publication, or actions outside approved workspaces.
- Do not read credentials, private keys, browser profiles, or secret files unless the user explicitly requests a narrowly scoped operation.
- Report exact files changed and verification performed.
